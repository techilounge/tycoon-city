# Product brief
## Vision
Original premium multiplayer property strategy game with fast social play and accessible mobile UX. Working title: Tycoon City.
## Audience
Friends, families, casual and competitive players.
## Modes
Classic, Quick, Blitz, private room, later ranked, team, AI, and custom boards. Target 2–8 players, start with 2–6.
## Gameplay
Server-rolled dice, turn order, movement, purchasable properties, ownership, rent, district bonuses, upgrades, mortgages, bankruptcy, live auctions, trade/counteroffer, event cards, timed turns, win conditions. All formulas require versioned documented rules.
## Multiplayer
Guest room codes, authenticated profiles later, presence, reconnect/resume, spectators later, chat moderation, authoritative event log, idempotent commands, snapshot/replay.
## Design
Premium dark navy/teal and restrained gold; responsive 2D first, 3D optional later; animation respects reduced motion. No protected Monopoly assets or names.
## Non-goals for starter
No real matchmaking, secure dice, server persistence, real auctions/trades, or payments are implemented in the initial demo.
